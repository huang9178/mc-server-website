# 正宗土豆服务器 - 桌面管理工具使用说明

## 快速开始（已有exe直接用）

如果你已经有 `土豆服务器管理工具.exe`，直接双击运行即可，无需安装任何东西。

---

## 自己打包成exe（没有exe时用）

### 1. 安装Python
- 下载：https://www.python.org/downloads/
- 安装时勾选 "Add Python to PATH"

### 2. 打包
- 双击 `build.bat`
- 等待1-2分钟
- 打包完成后，exe在 `dist` 文件夹里

## 设置
- 点右下角 "⚙️ 设置" 可以修改API地址
- 默认API地址：http://tudoumc.fucku.top:56768
- 设置会自动保存，下次打开不用重新设置

---

## 注意事项

1. **电脑要开着**：服务器运行在你的电脑上，电脑关了就控制不了
2. **网络要通**：需要能访问 http://tudoumc.fucku.top:56768
3. **首次使用**：如果连接失败，检查服务器和frpc是否在运行
4. **管理员权限**：建议右键"以管理员身份运行"

---

## 常见问题

**Q: 显示"连接失败"怎么办？**
A: 检查电脑是否开着，服务器和frpc是否在运行，网络是否正常。

**Q: 打包失败怎么办？**
A: 确保Python已安装并添加到PATH，网络能访问pypi。

**Q: exe被杀软误报怎么办？**
A: PyInstaller打包的程序有时会被误报，添加信任即可，源码是公开的。
